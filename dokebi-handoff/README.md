# DOKEBI · Paquete de handoff para Claude Code

1. Crea una carpeta vacía para el proyecto y copia dentro todo el contenido de este paquete.
2. Abre Claude Code en esa carpeta.
3. Pega el prompt de `PROMPT-ETAPA-1.md`.

## Contenido

- `CLAUDE.md` — reglas del proyecto, stack, tokens, SEO y accesibilidad. Claude Code lo lee automáticamente en cada sesión.
- `SPEC.md` — especificación sección por sección (contenido + motion), etapas y contenido pendiente.
- `PROMPT-ETAPA-1.md` — prompt para arrancar.
- `data/menu.json` — los 35 productos del menú extraídos del diseño.
- `design/` — exportes del diseño de Claude Design (desktop 1440, móvil 390, smiley y storyboard del hero original). Son el código fuente del diseño (no se renderizan solos); para verlo, usa el link del artifact en claude.ai.
